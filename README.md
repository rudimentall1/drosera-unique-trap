# Drosera Unique Traps

## TreasuryRapidDrainDetector

**Реальный security-кейс:**

Протокол хранит 1000 ETH в казначействе. Хакер получает доступ к приватному ключу и начинает выводить средства. За один блок выведено 300 ETH (>20%). Трап срабатывает и вызывает pause() на протоколе, останавливая дальнейший вывод. Спасено 700 ETH.

**Как работает:**
1. Собирает баланс казначейства каждый блок
2. Сравнивает с предыдущим значением
3. Если баланс упал больше чем на 20% за один блок — вызывает emergency pause

**Адрес (Hoodi):** `0x133d815B79D8ED4f824c77aF0E739bF75f19B56D`

**Тесты:** 3/3 passed (нет слива / быстрый слив / пустые данные)

**Конфиг:** `drosera-treasury.toml`

**Responder:** `TreasuryResponder.sol` — эмитит событие с деталями (предыдущий баланс, текущий, сумма вывода, процент)
